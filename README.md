# Azure AI Agents Labs
My lab work following the Microsoft Learn AI Agents course. Practicing Azure AI Foundry, custom function tools, MCP integration, agent orchestration, and remote agent communication.

## Labs

* Lab 01 - Build an agent in portal and VS Code with function calling
* Lab 02 - Custom function tools with an astronomy agent
* Lab 03 - MCP server integration
* Lab 04 - Integrate agent with Foundry IQ
* Lab 05a - M365 Teams integration
* Lab 05b - Work IQ integration
* Lab 06 - Build a workflow with Microsoft Foundry
* Lab 07 - Agent framework
* Lab 08 - Agent orchestration
* Lab 09 - Build remote agents with A2A communication

## Stack

* Azure AI Foundry
* azure-ai-projects SDK v2.2.0
* Python 3.11 / 3.13
